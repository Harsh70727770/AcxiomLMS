# 📚 Acxiom LMS  
### A Smart Learning Management System for Students, Teachers, and Admins

Acxiom LMS is a full-featured Learning Management System built using ASP.NET Core MVC, designed to streamline the management of courses, users, and enrollments in an intuitive and visually modern interface.

This project uses glassmorphism UI, beautiful backgrounds, and a clean structure suitable for college projects, internships, and real-world learning platforms.

---

## 🚀 Features

### 🔐 Authentication
- User Login & Registration  
- Roles: **Admin**, **Teacher**, **Student**  
- Session-based authentication system  

---

## 🧑‍🎓 Users Module
- View all users  
- Role-specific listing  
- Clean table UI  

---

## 📘 Courses Module
- Add, Edit, Delete Courses  
- Course Description & Instructor  
- Modern UI with glassmorphism  
- Backgrounds based on page type  

---

## 📝 **Enrollments Module**
- Assign courses to students  
- View and remove enrollments  
- User–Course mapping table  
- Transparent glass-style card UI  

---

## 🎨 Visual Design
The project includes:
- Full-screen background images  
- Glassmorphism cards  
- Transparent input controls  
- Navbar with search bar  
- Modern typography and layout  

---

## 🏗️ Tech Stack
- ASP.NET Core MVC (C#)
- Entity Framework Core
- Bootstrap 5
- SQL Server
- Razor Views
- CSS (Custom Modern UI)
